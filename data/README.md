# 合成输入数据

用于复盘预警响应的合成预警版本、人口暴露、送达回执、避难容量和处置记录。

所有记录均为虚构，仅供本地开发使用。日期与数值均为示例。

## 文件

- `warnings.csv`：预警版本，同一警告的多行表示同一版本覆盖多个区域。
- `population_delivery.csv`：社区/人口分组的暴露估计与消息回执。
- `shelters_response.csv`：避难点开放时段、容量与接纳登记。
- `fixture_manifest.csv`：样例文件清单。

样例故意保留了几种需要复盘的边界情况：

- `W100` 第 2 版才把 `East` 纳入覆盖，但 `East` 的联络记录在覆盖之后才发出；
  复盘不能把 `East` 说成提前收到通知。
- `North/older_adults` 有居民确认时间；`North/all` 只有发送记录；`East/all`
  渠道已送达但无确认——三者是不同状态。
- `SH01` 有接纳登记；`R01` 开放但容量为 0——不能因为「已开放」就认为有位置。

如需独立暴露与人口分组资料，可增加 `exposures.csv` 与 `groups.csv`（字段见
项目根目录 `README.md`）。未提供时，暴露人数由发送目标人数推导，并会在复盘
中标注为下限估计。
